# Notes

- Keep full document IDs separate from metadata series signatures. The client preserves the requested ID as `CaseDocument.document_id`; replacing it with metadata `Signatur` can break retrieval. Canonical field mappings and accepted payload shapes are in [API-DOCUMENTATION.md](API-DOCUMENTATION.md).
- Metadata `HTML.Datei` / `PDF.Datei` paths are untrusted. Validate decoded segments before joining them to the docs endpoint; quoting alone does not prevent dot-segment traversal.
- API models use Pydantic dataclasses to preserve existing positional constructors and dataclass behavior while validating typed fields. Configuration uses a frozen Pydantic model. Search source fields used by public properties are validated before use; unknown source fields remain available.
- A client library should propagate errors to callers rather than configure application-wide JSON logging or log exceptions that it re-raises. Database persistence and agent telemetry are not applicable to this download client.

- Current response contracts were verified directly on 2026-10-13; do not use the historical upstream PDF as a specification. Index changes are in `actions`, Jobs file statuses are in `dateien`, and `signaturen` contains summary counts. Checkpoints must retain job IDs and timestamps because sampled Index/last endpoints lagged Jobs/last by months.
- Scraper identities and court hierarchy IDs differ (e.g. CH_BPatG versus CH_PATG). The current search endpoint accepts scraper filtering through the `entscheidsuche.v2-<lowercase scraper>` `_index` value. Hit scraper names prefer explicit Spider/content directories, with canonical known-index fallback; unknown names are not guessed from court IDs. Facetten.json supplies current hierarchy-to-scraper mappings.
- Search count relation and sort values are retained. Typed parsing raises IncompleteSearchError for timeouts/shard failures, preserving partial results in the exception; raw search remains a passthrough. Offline fixture tests cover current response shapes, with explicitly opted-in live checks via `--live-api`.
- Returned hits/documents carry the configured docs endpoint, and model content URLs share path validation with client getters. `cache_dir` remains accepted only for compatibility and warns when non-None; it creates no directory and performs no caching.
